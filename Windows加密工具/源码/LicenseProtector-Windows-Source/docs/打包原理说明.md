# LicenseProtector 打包原理说明

开发者：Stephen Hu  
邮箱：stephenhu031028@gmail.com

## 1. 打包工具本身做了什么

LicenseProtector 是一个离线的 PHP 源码授权交付工具。它不会修改用户选择的原项目，而是先复制一份临时工作区，再在临时副本上完成签名、保护和归档。因此原项目仍然可以正常开发和部署。

图形界面中点击“生成交付包”后，流程如下：

1. 扫描项目并识别 PHP 入口文件，当前仅支持 PHP + Hyperf。
2. 规范化多个授权域名和多个服务器 IPv4 地址，生成唯一 License ID。
3. 使用厂商 Ed25519 私钥签名授权信息。
4. 将授权文件 `license.dat` 写入临时项目副本。
5. 写入 Watchdog 保护代码，并在入口文件中注入启动检查。
6. 对保护文件和授权文件计算 SHA-256，生成 `MANIFEST` 完整性清单，并使用厂商私钥对清单生成 `protected/watchdog/manifest.sig`。
7. 写入 `VERSION` 和部署说明 `INSTALL.md`。
8. 将交付目录和 ZIP 压缩包放入输出目录的 `history` 子目录，按 UTC 时间和 License ID 永久归档。

### 可选的免费源代码加固

可在图形界面中选择单个 PHP 文件或目录。工具只在临时交付副本上处理选中的 PHP 文件，使用本机 PHP 词法器移除普通注释和冗余空白，并在替换前执行 PHP 语法检查。文档注释会保留，避免破坏依赖注释的 Hyperf 项目。

这一步提高阅读和低成本复制的门槛，但不是不可逆加密，目标服务器不需要解密器或扩展。选中的处理结果会加入 `MANIFEST`，并受到其 Ed25519 签名保护。

完全自研的 LPBC 编码器、Linux Agent 和 PHP Loader 见 `docs/自研Loader协议.md`。它使用独立于 Zend opcode 的版本化容器；选中的文件输出为 `.lpbc`，Agent 密钥保存在服务器外置路径，清单和容器均有厂商签名。Loader 在目标 PHP ABI 的进程内存中解密并调用 Zend 编译器执行完整 PHP 源码；扩展必须按目标 Linux/PHP 版本构建并通过集成测试。

## 2. 运行时校验原理

客户部署交付目录后，PHP 入口首先加载 Watchdog。Watchdog 依次完成：

- 读取并验证 `license.dat` 的 Ed25519 签名；
- 检查当前域名或当前 IPv4 是否与授权范围匹配：多个域名和多个 IPv4 均为 OR 关系，任意一个命中即可通过。Hyperf 项目会自动生成并登记 HTTP 中间件，以便在每个请求到来时读取真实 Host；
- 检查 PHP 运行版本是否满足 License 中记录的最低版本，并要求服务器启用 sodium 扩展；
- 使用嵌入校验器的公钥验签；私钥绝不能放入客户包；
- 先验证 `MANIFEST` 的 Ed25519 签名，再校验其中记录的文件 SHA-256，发现文件、清单或清单签名被替换或篡改时立即拒绝运行。

整个运行时检查不需要网络连接，不会把源码或授权信息发送到服务器。目标环境固定为 PHP + Hyperf；打包时选择 PHP 最低版本（PHP 8.0+ 至 PHP 8.4+），服务器实际版本不能低于该选择。

## 3. 密钥位置和安全边界

LicenseProtector 安装包是**厂商签发工具**，不是给客户运行的授权运行时。它可以读取厂商私钥来签发新的 License，因此只能安装在厂商自己的电脑上；客户应当只收到生成后的 PHP 交付包，不能收到本安装包、`keys` 目录或 `vendor_private.pem`。

Windows 图形界面运行时默认使用：

```text
<软件安装目录>\keys\vendor_private.pem
<软件安装目录>\keys\vendor_public.pem
```

安装向导会为 `keys` 目录授予普通用户写入权限，便于首次启动后点击“生成厂商密钥”。安装目录由用户在安装向导中自行选择。私钥只用于厂商签发 License，应当备份到安全位置，绝不能发送给客户。

命令行模式仍然通过 `--private-key` 和 `--public-key` 参数指定路径，方便自动化构建。

## 4. Windows 安装包

PyInstaller 将 GUI 和 Python 运行时打包为单文件 `LicenseProtector.exe`。Inno Setup 再将该 EXE 制作成图形化安装包，提供：

- 用户自选安装目录；
- 开始菜单快捷方式；
- 可选的桌面快捷方式；
- 卸载入口；
- 安装完成后启动软件。

最终安装包为：

```text
installer_dist\LicenseProtector-Setup.exe
```

测试用的 `final_dist`、`final_build`、`dist`、`build`、`*.spec` 等构建缓存不属于交付内容。完成验证后会清理这些临时目录，只保留源码、文档和 `installer_dist` 中的安装包。
